# Example avatars

Sixteen OpenAvatar 0.1 documents, licensed CC BY 4.0 by Enconvo. Eight are
Enconvo's felt characters written in the shape language; Matcha is a plush
biped. Pixel, Bumble, Ember, Spike, Peachy Planet, Shy Snail and Sleepy
Teapot were made by an AI agent with the
[OpenAvatar skill](../skills/openavatar/SKILL.md), each in a few rounds of
render and fix; their `meta.generator` says so. They double as the first
conformance documents: the core package's tests validate every file here
against the JSON Schema and `validate()`, and the gallery shows them all.

| File | Shows |
|---|---|
| `bubble.openavatar` | superellipsoid in a smooth union with a tapered capsule; typing dots that `appear` while thinking |
| `beanbot.openavatar` | a smooth union scaled on z; an antenna part with a glowing bulb driven by `voice` |
| `mochi.openavatar` | `squash` deformer; a torus cut by a `halfspace`; cups that glow while listening |
| `sprout.openavatar` | `taper` deformer; leaves that `spin` while thinking, attached to a stem part |
| `starling.openavatar` | a puffed star `extrusion`; glasses from tori, a bent bridge and glass lenses |
| `cloudlet.openavatar` | five spheres in a smooth union cut flat; rain that `drift`s down while thinking |
| `sugar.openavatar` | a rounded box; a bowtie that pulses and sways with the voice |
| `jelly.openavatar` | `ripple` deformer; mirrored pom-pom tentacles that sway |
| `matcha.openavatar` | a `biped` with fur, a sewn face, an outfit, idle motions and an Enconvo extension |
| `pixel.openavatar` | a rounded box in `plastic` with `body.arms`; a dark screen `patch` with a `drawn` face; a bulb stacked `to` its antenna that glows while thinking |
| `bumble.openavatar` | a `stripes` pattern placed so the face sits on one band; glass wings that `flap` faster while `active`; upright antennae |
| `ember.openavatar` | a second `biped` with `velvet`, cone ears, muzzle and chest `patch`es, a `button` nose, and a lantern held in `left-hand` |
| `spike.openavatar` | `toon`; `bend`-curved arms and a `ripple`d column; a `clay` pot from a `cone`; a grumpy rest through `face.expressions.neutral` with brows |
| `planet.openavatar` | a floating `clay` planet; a flat ring from one cylinder `subtract`ed from another, turned with `rotation` and `spin`ning; a moon stacked `to` the ring; a star `extrusion` that `bob`s, `pulse`s and glows with the voice |
| `snail.openavatar` | `rubber` skin and a `plastic` shell; the shell's spiral as the `intersect` of a copy of the shell with an extruded spiral `stroke`; eye stalks that `sway`; a `relaxed` rest and its own reaction to `reading` |
| `teapot.openavatar` | `ceramic`; a spout, a `torus` handle and a lid cut with `halfspace`s; steam puffs that `appear`, `drift` and `bob` while thinking in place of the dots |
