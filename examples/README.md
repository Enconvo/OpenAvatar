# Example avatars

Twenty-four OpenAvatar 0.1 documents, licensed CC BY 4.0 by Enconvo. Eight are
Enconvo's felt characters written in the shape language; Matcha is a plush
biped. Pixel, Bumble, Ember, Spike, Peachy Planet, Shy Snail and Sleepy
Teapot were made by an AI agent with the
[OpenAvatar skill](../skills/openavatar/SKILL.md), each in a few rounds of
render and fix; their `meta.generator` says so. Quo, Duet, Mumble, Caret,
Isla and Wrap, Enconvo's brand plush yetis, and the faceless Aurora Halo and
Plush Pebble are ports of characters Enconvo draws in code, made by an AI
agent from that code's numbers and compared with the app's pictures. They double as the first
conformance documents: the core package's tests validate every file here
against the JSON Schema and `validate()`, and the gallery shows them all.
